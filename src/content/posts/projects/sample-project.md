This is a draft template for project posts. Copy this structure when you write
up a real project, then delete this file.

## What it is

Two or three sentences describing the project and who it's for.

## Demo

Screenshots go in `public/images/<post-slug>/` and are embedded like this:

```md
![Screenshot of the main screen](/playground/images/sample-project/main.png)
```

Or embed a live demo with an iframe (styled to be responsive automatically):

```html
<iframe src="https://example.com/demo" title="Live demo" loading="lazy"></iframe>
```

## Code

Repo: [github.com/tjwjdl23/example](https://github.com/tjwjdl23/example)

## How I built it

A short honest section: what the stack is, what was hard, what you'd do
differently. This is the part admissions officers and recruiters actually read.
