# 아리산 예매: 날짜·역 채우기 북마크

`public/alishan-autofill.html`: 아리산 삼림철도 온라인 예매 **첫 화면에서 탑승일·출발역·도착역만**
채워 주는 북마크(bookmarklet)를 만드는 설정 페이지다.

배포본: https://tjwjdl23.github.io/playground/alishan-autofill.html

## 하는 일 / 하지 않는 일

| 북마크가 하는 일 | 사람이 직접 하는 일 |
| --- | --- |
| 탑승일 칸 채우기 | 매수 선택 |
| 출발역 · 도착역 선택 | 인증문자 입력 |
| 인증문자 칸으로 커서 이동 | [다음] 버튼, 시간 · 구매자(여권) 정보, 결제 |

- 버튼을 누르거나 폼을 제출하지 않고, 반복 조회나 새로고침도 하지 않는다. 한 번 누르면 한 번 채우고 끝난다.
- 출발역을 바꾸면 도착역 목록을 새로 불러오는 화면을 위해, **페이지가 스스로 목록을 갱신할 때까지
  최대 3초 기다리기만** 한다. 사이트로 추가 요청을 보내지 않는다.
- 탑승 정보는 설정 페이지의 브라우저(localStorage)에만 남는다. 개인정보는 다루지 않는다.

## 칸을 찾는 방법

실제 예매 사이트의 HTML 을 여기서 확인할 수 없어서, 특정 id 에 기대지 않고 추론한다.

- **역 칸:** 옵션 중 역 이름(한자 · 영문 · 한글)이 2개 이상인 `<select>`. 라벨/id/주변 글자로
  출발(`起站`, `出發`, `from`, `start` …)과 도착(`迄站`, `到達`, `to`, `arrive` …)을 가르고,
  못 가르면 화면 순서(앞 = 출발)로 정한다.
- **탑승일:** `input[type=date]` → 이름/라벨에 날짜가 들어간 텍스트 칸(placeholder 나 기존 값의
  `/` · `-` 형식을 따름) → 옵션에 날짜가 들어 있는 `<select>` 순으로 찾는다.
- 못 찾은 칸은 건드리지 않고, 오른쪽 위 안내창에 **"직접 선택"** 으로 알려 준다.

`public/alishan-autofill-practice.html` 은 연습용 가짜 첫 화면이다. 예매 당일 전에 여기서 한 번 눌러 보고,
가능하면 실제 사이트에서도 미리 (오픈 전 날짜로) 눌러서 칸을 제대로 찾는지 확인해 두는 게 좋다.

## 테스트

```sh
cd tests/alishan-autofill
npm install
npm test
```

Playwright + Chromium 으로 설정 화면에서 북마크를 만들고, 연습 화면과 여러 형태의 가짜 첫 화면
(영문 · 라벨 없음 · 도착 칸이 먼저 나옴 · 날짜 드롭다운 · 없는 역/날짜)에서 실행해 결과를 확인한다.
Chromium 경로를 직접 지정하려면 `CHROMIUM_PATH=/path/to/chrome npm test`.
